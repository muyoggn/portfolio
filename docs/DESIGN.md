# デザインの設計メモ

> 2026-11-19 に、植物・ジャングルのテーマから「Layers（重なり）」のテーマに作り直しました。
> 以前のイラスト中心の設計は Git の履歴（PR #4〜#10）に残っています。

## 1. 目指したもの
- **シンプル**：1 画面に置く情報を少なくする。最初の画面は「名前」と「浮かぶ板」だけ
- **立体感**：平らな画面の中に、1 か所だけ奥行きのあるもの（板の重なり）を置いて印象を残す
- **独創性**：よくある「Hello, I'm」やカードの枠を使わない。板そのものがメニューになっている

## 2. ルール

| ルール | 理由 |
|---|---|
| 色は白・黒・グレー＋朱色 1 色 | 色数が少ないほど、差し色が目に入る |
| 朱色は「選んでいるもの・リンク・名前の最後の点」だけに使う | どこを押せるか、どこが大事かがすぐ分かる |
| 英字の見出しは字間を詰めて大きく、日本語の添え書きは小さく字間を広げる | 大小の差でメリハリを出す |
| 枠（カード）で囲まない。区切りは細い線だけ | 情報が同じでも、すっきり見える |
| 動き続けるのは最初の画面の板だけ | 読んでいる最中に視界で何かが動くと集中できない |
| OS の「動きを減らす」設定を尊重する | 動きで気分が悪くなる人への配慮 |

## 3. 場所ごとの工夫
- **最初の画面**：左に大きな名前、右に 5 枚の板。板にマウスを乗せると上の板が持ち上がり、選んだ板が朱色で顔を出す。押すとそのセクションへ移動。スクロールすると板の間隔が広がる
- **見出し**：大きな英字＋右肩に朱色の番号＋日本語。画面に入ると、寝かせた板が起き上がるように出てくる
- **Works**：作品のミニチュアを層に分けて組み立て、マウスで傾けると層ごとにずれて立体的に見える。本物のスクリーンショットを用意したら差し替え可能
- **スマホ**：ヘッダーの文字メニューは隠し、最初の画面の板をメニュー代わりにする
