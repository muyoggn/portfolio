# GitHub 入門（はじめての人向け）

## GitHub とは？

一言でいうと **「コードを置いておくインターネット上の保管庫」** です。

- **バックアップ**：PC が壊れてもコードが消えない
- **変更履歴（タイムマシン）**：「いつ・どこを・なぜ変えたか」が全部残り、昔の状態にも戻せる
- **見せる場所**：就活で「GitHub の URL」を渡すと、どんなコードを書いてきたか見てもらえる
- **公開の起点**：Cloudflare は GitHub のコードを見て、自動でサイトを公開・更新してくれる

### Git と GitHub の違い
- **Git（ギット）**：変更履歴を記録する「仕組み（ソフト）」。手元の PC で動く
- **GitHub（ギットハブ）**：Git の記録をネット上に置ける「サービス（Web サイト）」

例えるなら、Git は「日記の書き方」、GitHub は「日記を預けておく貸金庫」です。

### 覚えておく言葉（4つだけ）
| 言葉 | 意味 |
|---|---|
| リポジトリ（repository） | 1つのプロジェクト用の保管庫。今回は `portfolio` という名前で1つ作る |
| コミット（commit） | 変更を「セーブポイント」として記録すること |
| プッシュ（push） | 手元のセーブポイントを GitHub に送ること |
| Public / Private | 誰でも見られる公開リポジトリ / 自分だけが見られる非公開リポジトリ |

今回は、コミットとプッシュは **Claude が代わりにやります**。あなたがやるのは下の3ステップだけです。

---

## ステップ1：アカウントを作る

1. https://github.com/signup を開く
2. メールアドレスを入力 →「Continue」
3. パスワードを決める
4. **ユーザー名（Username）** を決める
   - 就活で URL（`github.com/ユーザー名`）として見られるので、読みやすく、ふざけすぎないものがおすすめ
   - 例：`go-tanaka`、`gou-dev`（英数字とハイフンのみ）
5. 「Continue」→ パズルなどの本人確認 → メールに届いた数字（確認コード）を入力
6. 途中で「How many team members…」などの質問が出たら、「Just me」や「Skip personalization」で飛ばしてOK
7. プラン選択が出たら **Free（無料）** を選ぶ

## ステップ2：リポジトリ（保管庫）を作る

1. GitHub にログインした状態で、右上の **「＋」** →**「New repository」**
2. 次のように入力する
   - **Repository name**：`portfolio`
   - **Description**（任意）：`自分のポートフォリオサイト`
   - **Public** を選ぶ（就活で見せるため。パスワードなどの秘密はコードに入っていないので大丈夫）
   - **「Add a README file」「.gitignore」「license」は全部オフのまま**（中身はすでにこちらにあるので、空の保管庫が必要）
3. 緑の **「Create repository」** を押す
4. 説明だらけの画面が出たら成功です。ここに書かれたコマンドは使わないので閉じてOK

## ステップ3：Claude と GitHub をつなぐ

Claude があなたの代わりにコードを置けるように、許可を出します。

1. https://claude.ai/connect-github を開く
2. GitHub の画面に切り替わったら **「Authorize」**（許可）を押す
3. 「Claude」アプリをインストールする画面になったら
   - インストール先にあなたのアカウントを選ぶ
   - **「Only select repositories」** を選び、`portfolio` にチェック（必要なリポジトリだけに許可を絞る方が安全）
   - **「Install」** を押す

終わったら、スレッドに **GitHub のユーザー名** を書いてください。Claude がコードと変更履歴をアップロードし、`https://github.com/ユーザー名/portfolio` で見られるようにします。

---

## うまくいかないとき

- **確認コードのメールが来ない**：迷惑メールフォルダを確認、または数分待って「Resend」
- **ユーザー名が使えない**：すでに誰かが使っているので、数字やハイフンを足す
- **どこかで止まった**：その画面に書いてある英語の文や、スクリーンショットをスレッドに貼ってくれれば案内します
